## What is original to this release

- The explicit separation of a future spinal interface from a desktop reference.
- Paired synthetic studies, their controls, parameter sweeps and failure cases.
- Application-to-pulse digital integration and portable timing/fault reference.
- A one-channel artificial-signal/test-load circuit and matching PCB.

interfaces or discovered a clinically effective intervention. Model laws and
synthetic plasticity parameters are choices to investigate, not measured biology.

## Data integrity

All new study/electrical data are generated by code. Each dataset records the
chosen seeds, equations, units and assumptions. Confidence intervals quantify
Monte Carlo variability under those assumptions; they do not quantify uncertainty
about the biological mechanism. No participant IDs, clinical recordings or
privileged personal data are present. No GitHub credentials are stored here.

See `environment.json`, `verification.json`, `manifest.sha256` and
`docs/claim-register.csv` for the execution environment, verification receipts,
artifact hashes and claim boundaries.

The SHA256 manifest hashes staged Git blob bytes (including Git's LF text
normalization), so it represents the committed release rather than a particular
Windows working copy's line endings. It excludes itself to avoid a self-hash.

## Full-system overhaul: Stage 2, 8 October 2026

The owner requested continuation. AI research, electronics and control workstreams
audited primary/manufacturer sources and specified numerical inputs; root
integration aligned rates, memory, cycle reservations and timing, reproduced
budgets, authored figures/brief and generated the preliminary build123d/FreeCAD

remain attributed; no proprietary CAD or biological recording is redistributed.

feasibility witnesses with unqualified implant suitability. No human has yet
endorsed the final components, anatomy or operating profiles. Review receipts
describe AI-assisted technical/visual checks, not an independent licensed design
audit or biological trial. Native electronics implementation and populated
engineering CAD remain later stages. See `stage2-verification.json`,
`stage2-review.json` and the Stage 2 progress table for the exact scope.
