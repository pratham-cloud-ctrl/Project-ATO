# Actual reference-clearance probe evidence

This folder preserves a completed read-only native FreeCAD distance investigation
from 16 October 2026. The five archived execution records are copied byte for
byte from the actual temporary files. The local Git attributes preserve those
bytes across platforms; `manifest.json` records their original SHA256 values,
the executed source LF-normalized SHA256, and the frozen native/contract bindings.

The probe completed all **14** declared clearance checks in **310.47 seconds**,
using **1,727 actual BRep solid-pair distance queries** and conservatively pruning
**1,317** other pairs. All eight board-to-own-tray minima were **8.615 mm** against
8 mm gates. Five upper-tray minima were **27.845 mm**; power to current-driver was
**24.785 mm**, against 20 mm gates. The original numerical acceptance tolerance
of 0.00002 mm was retained. These are nominal digital distances, not manufacturing
or physical-test results.

`executed-probe.py.txt` is the exact source that produced `raw-results.json` and
`raw-execution.log`; its original Windows workspace path is intentionally intact.
It is archival evidence, not the portable project entry point. `raw-summary.json`
is a separate actual post-run hash-verification/condensation. `raw-topology.json`
is a separate actual inline traversal showing all 16 queried object trees contain
1,676 solid leaves and no omitted face/edge-only leaves. Those two inline helpers
are not misrepresented as having been generated by the archived probe source.

The final independent reference driver verifies these recorded source/data
bindings against the current saved native assembly, reopens its real shapes,
checks complete solid coverage and the recorded winning solid pairs, and performs
a fresh material-interference pass. Any reused successful STEP/native inspection
phases retain their separate executed-source/checkpoint provenance. This archive
alone is not a reconstructed full reference-inspection pass and does not claim
fabrication, load, thermal, electrical or implant qualification.
